# astronlin.github.io

Personal website of Lingrui Lin.

The main pages are rendered by `assets/site/app.js`. Chinese translations are
maintained in `assets/site/i18n.js`; English remains the default. Chinese prose
is written for Chinese readers rather than translated sentence by sentence,
while retaining the same facts and scientific qualifications. The header
language switch remembers the visitor's choice. Direct links can specify
`?lang=zh#research` or `?lang=en#research`.

Publication titles and author lists, figure labels, CV PDFs, and the standalone
interactive tools retain their original language. When updating the English
page text, update its matching Chinese entry in `i18n.js` as well.
